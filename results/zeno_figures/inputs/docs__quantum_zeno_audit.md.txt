## 2. Mathematical formulation

The fixed basis is
\(|00\rangle,|0r\rangle,|r0\rangle,|rr\rangle\). With
\(c=\Omega e^{-i\phi}/2\), the unchanged milestone convention is

\[
\bar H=H/\hbar=
\begin{pmatrix}
\Delta&c&c&0\\c^*&0&0&c\\c^*&0&0&c\\0&c^*&c^*&V-\Delta
\end{pmatrix}.
\]

All frequencies are angular frequencies in rad/s, time is seconds, and
\(U(t)=e^{-i\bar Ht}\). The study uses
\(\Omega=2\pi\,10^6\), \(\Delta=\phi=0\),
\(V/\Omega=0,1,10,100\), \(T=0.5\,\mu\mathrm{s}\), and initial
\(\rho_0=|00\rangle\langle00|\). Thus the interaction values also equal
\(V/(2\pi)\) in MHz. There is no varying Hamiltonian in this extension.

## 3. Density-matrix implementation

`density_from_state` implements `outer(psi, psi.conj())`; `evolve_density`
implements \(U\rho U^\dagger\) using the full 4×4 matrix. Neither routine
normalises, clips eigenvalues, resets populations or repairs an invalid state.
Validation uses absolute tolerance \(10^{-10}\) for accumulated density
roundoff; input pure states and projectors use \(10^{-12}\).

The audit compares full complex matrices, not just plotted probabilities:

| Saved unmeasured matrices vs independent spectral propagation | 1.18×10⁻¹⁴ |
| Saved unmeasured purity vs 1 | 4.87×10⁻¹⁴ |
| Trace vs 1 over all 24,192 saved matrices | 8.34×10⁻¹³ |

| Saved final matrices vs independent channel powers | 1.44×10⁻¹¹ |

The independent audit constructs the Hamiltonian explicitly and diagonalises it
with NumPy, whereas production uses SciPy's matrix exponential. Spectral
unitarity roundoff can accumulate through 10,000 channel applications; the
last comparison uses a stated absolute tolerance of 2×10⁻¹¹. Production trace
drift is smaller. No discrepancy is concealed by normalisation.

Tests additionally check pure and mixed initial states, purity preservation,
negative times, nonzero phases/detunings, both interaction signs and invalid
inputs. `zeno_audit_examples.npz` retains actual example matrices for inspection.

## 4. Measurement model

For ground-state survival,

\[
P=\operatorname{diag}(1,0,0,0),\quad
Q=\operatorname{diag}(0,1,1,1),\quad
\mathcal D(\rho)=P\rho P+Q\rho Q.
\]

For an arbitrary input matrix this channel produces

\[
\begin{pmatrix}
\rho_{00}&0&0&0\\
0&\rho_{11}&\rho_{12}&\rho_{13}\\
0&\rho_{21}&\rho_{22}&\rho_{23}\\
0&\rho_{31}&\rho_{32}&\rho_{33}
\end{pmatrix}.
\]

This preserves the whole Q block, rather than measuring each computational
basis state separately. The numerical example
\(\psi=(1,i,2,3i)^T/\sqrt{15}\) retains
\(|\rho_{0r,r0}|=2/15\), removes all P/Q coherences exactly, preserves trace
within 2.23×10⁻¹⁶ and changes purity from 1 to 197/225 ≈ 0.875556. Its minimum
eigenvalue is −1.49×10⁻¹⁷. This is mixing from discarded outcomes, not a reset.

For M>0, measurements occur at \(kT/M\), k=1,…,M, including the endpoint.
M=0 means no measurement. M=1 cannot change endpoint P00 because the only
measurement occurs after the unitary evolution. Event samples are post-measurement.

**Resolved defect:** `searchsorted` previously interpreted some nominal event
times on the 1001-point display grid as one floating-point step before the
event. At M=10 and M=100, saved event coherences reached 0.151955 and 0.015702,
respectively. The lookup now recognises times within four ULPs of an event.
Regression tests compare independently generated grids and also check that
physically distinct samples before and after the event remain distinct.
Regenerated event coherences are zero. Final density matrices are unchanged;
trajectory populations changed by no more than 2.23×10⁻¹⁶.

The production repeated-measurement calculation is **non-selective**: outcomes
are discarded, and histories that leave P and later return contribute to final
\(P_{00}=\operatorname{Tr}(P\rho)\). Separately, `exact_all_yes` stores the
**joint probability of obtaining the P outcome at every measurement**. It is
not the normalised conditional state's P00, which is trivially one immediately
after a successful rank-one projection. A branch-enumeration test sums all
unnormalised outcome branches and recovers the non-selective density matrix.

## 5. Analytical Zeno prediction

Let \(\mu_n=\langle00|\bar H^n|00\rangle\). Direct matrix multiplication gives

\[
\bar H|00\rangle=\Delta|00\rangle+
\frac\Omega2e^{i\phi}(|0r\rangle+|r0\rangle),\quad
\mu_1=\Delta,\quad \mu_2=\Delta^2+\Omega^2/2.
\]

Hence \(a=\sigma_{\bar H}^2=\mu_2-\mu_1^2=\Omega^2/2
=1.9739208802178715\times10^{13}\,\mathrm{s}^{-2}\), independent of V,
Δ and φ. The Zeno time is \(a^{-1/2}=0.225079079\,\mu\mathrm{s}\).
The audit evaluates these moments without invoking any propagator. An
unnecessary production call to `unitary_operator(Hbar, 0)` in variance
validation was replaced by a direct Hermiticity check; a test forbids
propagator calls during this analytical calculation.

Expanding the survival amplitude,
\(A(\tau)=1-i\mu_1\tau-\mu_2\tau^2/2+\cdots\), yields

\[
p(\tau)=|A(\tau)|^2=1-a\tau^2+O(\tau^4).
\]

There is no cubic term because \(A(-\tau)=A(\tau)^*\). A useful independent
zero-interaction check is \(p(\tau)=\cos^4(\Omega\tau/2)\), whose expansion
is \(1-\Omega^2\tau^2/2+5\Omega^4\tau^4/48+O(\tau^6)\).

For selective all-P records, the rank-one projection restores the same
conditional state after every success, so, exactly,

\[
S_{\rm all\ yes}=p(T/M)^M.
\]

Taking logarithms and using fixed T and finite Hamiltonian gives

\[
\log S_{\rm all\ yes}=-aT^2/M+O(M^{-3}),\qquad
S_{\rm quad}=[1-a(T/M)^2]^M\simeq e^{-aT^2/M}.
\]

Here \(aT^2=\pi^2/2=4.934802200545\). The quadratic base is negative at
M=1,2, so those approximation entries are explicitly NaN, not probabilities.
The exponential is an asymptotic comparison, not an exact finite-M law.

For the non-selective channel, each step loses \(a\tau^2\) from an occupied
P sector. Its accumulated Q population is O(Mτ²). Returning Q→P adds a further
O(τ²) per step times that population; summed return contributions are
O(M²τ⁴)=O(M⁻²). Thus

\[
P_{00}^{\rm ns}(T;M)=1-aT^2/M+O(M^{-2}),\qquad
P_{00}^{\rm ns}-e^{-aT^2/M}=O(M^{-2}).
\]

The selective product and non-selective final occupation therefore have the
same leading loss but different finite-rate values. The report does not equate them.

## 8. Measurement-operator dependence

All existing projectors were checked explicitly for Hermiticity, idempotence,
completeness and orthogonality:

| Question | Yes projector | No projector | Physical meaning |
|---|---|---|---|
| A: ground | diag(1,0,0,0) | diag(0,1,1,1) | No excitation versus at least one excitation |
| B: any excitation | diag(0,1,1,1) | diag(1,0,0,0) | Same two subspaces, reversed outcome labels |
| C: double | diag(0,0,0,1) | diag(1,1,1,0) | Double excitation versus zero or one |

A and B have exactly the same non-selective channel, including for a general
mixed state. They do not resolve which atom is excited. B is an instantaneous
question; “ever excited” would require a measurement record and is not modeled.

C leaves a multidimensional subspace with coherent |00⟩↔|Ψ+⟩ motion. Its
projected Hamiltonian retains coupling Ω/√2, so at Δ=0 its large-M limit is
P00=cos²(ΩT/√2)=0.366872329 and Prr=0. At V=0, M=10000 gives
P00=0.366728323, PΨ+=0.632971506 and Prr=0.000300171. This differs markedly
from A's P00≈0.999507. Confinement to a subspace can preserve internal
motion, as described in the [Facchi–Pascazio review](https://arxiv.org/abs/0903.3297).

## 9. Interaction with Rydberg blockade

Blockade is already present in the unmeasured unitary model; it detunes |rr⟩
and inhibits double excitation. Repeated A measurements instead inhibit
departure from |00⟩. Comparison at the same T separates the two effects:

| V/Ω | Unmeasured final Prr | Unmeasured maximum Prr | A, M=10000: final Prr | Measurement gain in final P00 |
|---:|---:|---:|---:|---:|
| 0 | 1 | 1 | 3.00171×10⁻⁴ | 0.999506710 |
| 1 | 0.502115631 | 0.563417177 | 1.86974×10⁻⁴ | 0.873795220 |
| 10 | 0.003112956 | 0.005685481 | 4.78937×10⁻⁶ | 0.635884551 |
| 100 | 3.16512×10⁻⁵ | 5.06934×10⁻⁵ | 4.93129×10⁻⁸ | 0.632666671 |

The gain is measured P00 minus the unmeasured P00 at the same V, not a
comparison between different interactions. At V=100, blockade still leaves
PΨ+=0.633128257 at T without measurement. Thus small Prr alone is not
ground-state freezing and is not evidence of a Zeno effect.

## 10. Numerical convergence

The physical interval is τ=T/M. Production uses one static matrix exponential
for that whole interval; there is no numerical integration timestep. SciPy
uses a scaling-and-squaring/Padé matrix-exponential algorithm, not an ODE
time grid. [SciPy `expm` documentation](https://docs.scipy.org/doc/scipy/reference/generated/scipy.linalg.expm.html)
describes that algorithm. The 1001-point plotting grid has spacing **0.5 ns**
and does not subdivide propagation or trigger extra measurements.

At fixed M=5 and M=100, the audit replaces U(τ) by
\([U_{\rm spectral}(\tau/L)]^L\), L=1,2,4,8, while retaining exactly the same
measurement schedule. Across all four V values, the largest final-matrix
difference is **8.04×10⁻¹³**. There is no truncation-error convergence trend
to fit: these are mathematically equivalent constant-H propagators differing
at roundoff. Separate tests prove display-grid independence and event semantics.
Changing M therefore changes the physical experiment, not an ODE tolerance.

There is no H(t) path to validate here. This audit does not certify a
time-dependent Zeno extension; such a calculation would require an independent
integration-step convergence check.

## 12. Limitations

These are ideal instantaneous projectors with no detector dynamics, finite
measurement duration, inefficiency, spontaneous emission, motion or laser noise.
The maximum rate is 2×10¹⁰ s⁻¹, τ=0.05 ns; this is a mathematical limit
study and not an experimental feasibility claim. Only one T and nonnegative V
are plotted, though tests cover additional signs, phases and detunings.

Four high-rate points support the fitted residual order; they are not a proof
of an infinite-rate limit. Short-time residuals eventually reach floating-point
cancellation. The display grid does not resolve every intermeasurement arc at
large M. The event snapping tolerance resolves only floating-point ambiguity,
not finite detector timing uncertainty. No anti-Zeno claim is supported or made.
